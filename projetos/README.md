# Portfólio de Projetos Teamwork

Este diretório reúne registros de projetos em avaliação ou aprovados. Não cadastrar projetos fictícios para preencher a estrutura.

## Estrutura recomendada
Cada projeto terá pasta com ID e nome curto, por exemplo: TW-AAAA-NNNN-nome-do-projeto/.

Conteúdo sugerido:
- README.md: charter, objetivo, patrocinador, diretoria responsável, estado e links.
- plano.md: escopo, entregáveis, cronograma, recursos, dependências e riscos.
- status/: relatórios periódicos.
- decisoes.md: decisões e aprovações.
- entregas/: índice de entregáveis e evidências; evitar duplicar arquivos grandes sem necessidade.

## Regras
Só marcar aprovado após decisão registrada. Cada projeto aponta para responsável e critérios de aceite. PMO mantém visão consolidada, mas o diretor funcional responde pela qualidade especializada. Não armazenar segredos, tokens ou dados pessoais desnecessários.
