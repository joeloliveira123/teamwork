# Protocolos Transversais

- fluxo-de-demandas.md: entrada, triagem, classificação e encerramento.
- delegacao-e-handoff.md: transferência de tarefas entre diretorias.
- comunicacao-e-escalonamento.md: comunicação, níveis de decisão e incidentes.
- controle-de-mudancas.md: avaliação e aprovação de alterações.

Uma tarefa só atravessa diretorias quando contexto, responsável, entregável, restrições e critérios de aceite estão claros. Silêncio não é aceite.
