# Matriz de Responsabilidades

## Papéis
CEO; Diretoria Executiva; Diretor funcional; ATEI; PMO; SEC; solicitante/patrocinador; validador independente quando necessário.

## Matriz RACI simplificada
| Atividade | CEO | Dir. Exec. | Diretor funcional | ATEI | PMO | SEC |
|---|---|---|---|---|---|---|
| Objetivos corporativos | A | R/C | C | I | C | C |
| Registrar e triar demanda | I | C | C | I | A/R | C |
| Solução técnica da área | I | C | A | R | C | C |
| Plano integrado do projeto | A* | C | R | R | A/R** | C |
| Execução especializada | I | I | A | R | C | C |
| Coordenação de dependências | I | C | R | R | A/R | C |
| Validação funcional | I | I | A | R* | C | C |
| Monitoramento de portfólio | I | C | R | I | A/R | C |
| Mudança material | A | C | R | C | C | C |
| Gasto/contrato/produção | A | C | C | I | C | C |
| Avaliação de controles | I | I | R | C | C | A/R |
| Aceitação de risco relevante | A | C | R | I | C | C |

R = executa; A = responde pela decisão/resultado; C = consultado; I = informado.
* CEO é A quando exceder delegação; caso contrário, patrocinador formalmente autorizado pode aceitar. Entrega crítica deve ter validador independente do autor.
** PMO responde pelo processo de planejamento e integração, não pela solução técnica ou orçamento.

## Regras
1. Uma atividade deve ter um A claramente identificado. Ambiguidade é escalada.
2. O diretor funcional mantém responsabilidade pela qualidade da área mesmo ao delegar.
3. PMO coordena o processo, não toma decisões técnicas por outras diretorias.
4. SEC pode recomendar pausa preventiva por risco grave; aceitação de risco segue alçada humana.
5. Autor não é único validador de entrega crítica.
6. Alterações nesta matriz de autoridade exigem aprovação do CEO.
